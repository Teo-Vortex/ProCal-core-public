Realm backup control

Realm data stays under the realm admin's control. New backups are encrypted as .procalbak packages and are useful only with the backup key saved outside the platform.

Manual export rule Export an encrypted full backup, download it, and store the file plus key somewhere outside this server. Control platform backups do not contain this realm's calendar, tasks, chat or uploaded files.

Export encrypted backup

The key is generated in the browser prompt. The backup downloads directly and is not retained on this server.

Encrypted_Backup_Warning_26.04.01
Full includes database content and config/files snapshot. Working is database-only. Both require the same key flow for validate and restore. The key PDF downloads before the backup file.

No automatic realm backups

Realm backups are not scheduled, retained or rotated by the platform. The realm admin owns the exported file and key.

There is no server-side backup catalog. Validate and restore upload a backup file only for that operation, then the temporary server copy is deleted.

Validate or restore from your file

Select a backup file from your computer. The file is uploaded temporarily and removed from the server after validate or restore.

Restore is destructive for this realm. It does not affect Control metadata or other realms, but it replaces this realm database content and, for full backups, config/files snapshot.
Users keep their own backup files and key PDFs. ProCal does not keep a restore list for realm backup packages.

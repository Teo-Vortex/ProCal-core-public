# Security Policy

Please report security issues privately.

Do not include secrets, production data, backup keys, passwords, Firebase service accounts, or private `.env` files in reports.

## Supported Versions

Only the latest published ProCal Core release is intended to receive security fixes unless a release note says otherwise.

## Reporting

Before the public security contact is finalized, report privately to the project owner or maintainer who gave you access to the release.

After the public repository is created, replace this section with the official security email or GitHub private vulnerability reporting link.

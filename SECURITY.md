# Security Policy

Please report security issues privately.

Do not include secrets, production data, backup keys, passwords, Firebase service accounts, or private `.env` files in reports.

## Supported Versions

Only the latest published ProCal Core release is intended to receive security fixes unless a release note says otherwise.

## Reporting

Use GitHub private vulnerability reporting:

https://github.com/Teo-Vortex/ProCal-core-public/security/advisories/new

Do not open a public issue for an unpatched vulnerability. Include the affected
version, reproduction steps, impact, and any suggested mitigation without
attaching real user data or credentials.

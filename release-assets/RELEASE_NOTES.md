## ProCal Core Public v0.9.9-beta.4

This release includes the self-hosted Core application, one-click container updates, improved profile and mobile links, and the signed ProCal Android application.

### Android application

- Download `ProCal-Android-v0.9.9.apk` below.
- Android 8.0 or newer is required.
- The application can save and switch between multiple ProCal Core servers.
- Attendance NFC tags are detected automatically while the app is open.
- The main screen includes a QR scanner that routes attendance and inventory codes to the correct module.
- Attendance stations can also be scanned from the attendance screen by QR code.
- Inventory item QR codes can be scanned from the app.
- App content now stays clear of the Android status and navigation bars.
- This APK is build revision 4 and updates the previously published v0.9.9 APK.
- Installation-specific Firebase credentials are not bundled in the APK. Push notifications are configured by each Core administrator.

The APK is signed with the ProCal Android release certificate. Its file checksum is provided in `SHA256SUMS.txt`.

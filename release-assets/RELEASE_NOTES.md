## ProCal Core Public v0.10.1-beta.1

This beta release expands the self-hosted Core with collaborative task workflows, attendance and inventory operations, a more responsive calendar interface, and complete colleague-facing guides in Bulgarian and English.

### Highlights

- Dated tasks and ongoing work now share one task workspace with status filters, completion history, invitations, personal/shared visibility rules, and report integration.
- Shared-calendar tasks remain visible to the team, while personal-calendar planning remains limited to the owner and accepted participants.
- Attendance includes personal and team history, calendar-day summaries, stable QR/NFC station codes, and controlled code rotation.
- Inventory includes multiple locations, receive/issue/transfer/stocktake operations, movement corrections, stable item QR codes with SKU labels, thresholds, and notification settings.
- Calendar task indicators, event previews, compact panels, responsive layouts, dark/light theme consistency, and the day timeline have been refined.
- The user guides now cover registration and every current module, including reports, compensations, media monitoring, backups, updates, QR, and NFC.
- The updater handles retained rollback containers correctly during future one-button updates.

### Android application

- Download `ProCal-Android-v0.10.1.apk` below. Android 8.0 or newer is required.
- The APK is build revision 5 and is signed with the same persistent ProCal release certificate as the previous public build.
- The application can save and switch between multiple Core servers, select one notification source, scan attendance/inventory QR codes, and read attendance NFC tags while open.
- Installation-specific Firebase credentials are not bundled. Each Core administrator configures optional push notifications for their own installation.

The APK checksum is provided in `SHA256SUMS.txt`.
